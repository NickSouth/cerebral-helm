Native window mockups

Six directions, two per surface. Each page has an A / B switch at the bottom. Everything floats over a mock desktop, and the blur you see is the same operation NSVisualEffectView will perform on the real one — so this is a truthful preview of the vibrancy, not an impression of it.

Settings A · macOS System Settings shape — searchable sidebar, grouped rows.
B · Icon-grid landing you drill into, frequent toggles surfaced. Window manager A · True 3D wheel — cards tilt away from the centre line.
B · Same cards, scale and opacity falloff only. Both fade into the desktop at each end. More Apps A · Generous grid, big icon over label, whole tile lifts.
B · Denser and sectioned, with a dock-style swell. Project detail × Linear A · Stacked — the cycle list takes over the "Live status" placeholder, one scroll.
B · Tabbed — Brief / Cycle, the list gets the whole window. Real Cycle 2 data.

Not production code — nothing under src/ is touched and the folder deletes in one command. They do pull in the real token layer, so the colours, radii and type are the ones the app actually ships.
